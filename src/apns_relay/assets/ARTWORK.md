# Relay artwork

Generated with the built-in image generation tool on 20 October 2026.
The PNG logo preserves transparency. Favicon and touch icon are resized derivatives.
The generated background is encoded as WebP for delivery.

## Logo prompt

Use case: logo-brand. Asset type: icon/logo for apns-push-relay, an open source push notification relay. Create one distinctive simple geometric symbol: three rounded signal strokes passing through a central angular relay chevron, suggesting a forward-moving notification. Bold clean silhouette legible at favicon size. Teal and ice-blue, flat vector-like finish, no gradients needed, no text, no letters, no Apple logo, no bell, no mockup, no shadow. Centered square composition with generous transparent padding. Actual transparent background.

## Background prompt

Use case: stylized-concept. Asset type: wide background image for the landing page of apns-push-relay, an open source privacy focused push notification relay. Create a sophisticated abstract visualization of luminous teal and icy blue signal paths relaying through a single glass prism to a small constellation of endpoints. Deep midnight navy background, restrained fine grain, subtle atmospheric glow, premium technical editorial art. Composition: wide landscape, visual activity primarily on the right half, left half very dark quiet negative space for HTML headline. No text, letters, logos, UI, watermark, Apple symbols or padlocks. Crisp refined lines, avoid busy cyberpunk aesthetic.
